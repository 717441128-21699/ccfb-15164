# 沧澜海钓 · 潮汐天气引擎重做

替换原来"一条正弦曲线"的假潮水，改为**调和常数潮汐模型 + 确定性天气引擎**，全部计算在 **Web Worker** 中完成，TypeScript 严格模式。

## 验收指标

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 潮位精度（vs 独立参考实现） | 偏差 < 1 cm | 最大 **0.53 mm**（5250 个样本全部 <1mm） |
| 30 钓点 × 30 天潮汐计算 | < 500 ms | 平均 **≈120 ms**（Node，5 次均值，含 14 万潮位点 + 3000+ 高低潮） |
| 分潮 | M2/S2/K1/O1 等 | **8 个**：M2 S2 N2 K2 K1 O1 P1 Q1 |
| 钓点潮型 | 半日/全日/混合都有 | 12 半日潮 + 12 混合潮 + 6 全日潮（共 30） |
| 测试 | — | 23 个用例全绿（含 worker_threads 端到端） |

## 页面

1. **潮汐日历** — 月历每日高低潮速览，点击日期看当日潮位过程线（总潮高实线、纯天文潮虚线、高低潮时刻/潮高明细表、最大气象增水）。
2. **钓点地图** — SVG 虚构海图，按潮型三色标注 30 个钓点；点击查看该点 8 分潮振幅、形态系数、水深等调和常数卡片，并可跳转其他页。

4. **出钓计划** — 3 小时窗口的鱼情活跃度与抛竿距离评分、安全等级与解释；30 钓点鱼情排行榜；计划本地收藏。

## 调和潮汐模型

每个钓点一套常数（`src/data/spots.json`），潮高：

```
h(t) = Z0 + Σ_c f_c · H_c · cos(V_c(t) + u_c − g_c) + surge(t)
```

- `H_c, g_c`：各分潮振幅与区时迟角（合成生成）
- `V_c`：Schureman 平衡潮天文幅角（τ、s、h、p、N 组装）
- `f_c, u_c`：18.61 年交点因子与订正角（M2/K1/K2/O1 三角展开，S2/P1 为 1/0）
- 形态系数 `F = (H_K1 + H_O1) / (H_M2 + H_S2)`：`<0.25` 半日潮，`0.25~3` 混合潮，`≥3` 全日潮

### 为什么快引擎能又快又准

- **快引擎**（`engine/tide.ts`）：按本地日锚点冻结 f/u，相位用分潮角速度 σ 线性外推，每日只算一次完整天文公式。
- **参考实现**（`engine/reference.ts`）：每个时刻全量重算天文幅角与交点因子，两条代码路径独立，仅在测试中交叉验证。
- 交点变化在一天内的相位漂移 <0.001°，对应亚毫米误差；f/u 按日刷新，长期不累积。

## 天气与气象增水

`engine/weather.ts`，由钓点种子 + 世界时间确定性生成（可复现、离线）：

- **气压**：3~5 天尺度移动高压/低压正弦场叠加（约 ±12 hPa）
- **逆气压效应**：每低于标准气压 1 hPa，水位抬升 **9.9 mm**（`(1013.25 − P) × 0.0099`）
- **风增水**：向岸风分量 × 风速平方 / 水深
- **风浪**：简化 SMB 成长 + 浅水限幅，给出有效波高/周期
- 风、气压、降雨、波高再输入 `engine/plan.ts` 影响鱼情活跃度与抛竿距离指数

## 目录结构

```
src/
  engine/        # 纯计算引擎，不依赖 DOM，可在 Node/Worker 复用
    astronomy.ts  Schureman 天文幅角 + 交点订正
    tide.ts       快速调和引擎、日缓存、潮位序列
    reference.ts  独立全量参考实现（仅测试用）
    weather.ts    天气场 + 逆气压/风增水
    extremes.ts   导数二分精化高低潮
    plan.ts       鱼情/抛竿/安全评分
  workers/       # Web Worker 入口、协议、Promise 客户端
  ui/pages/      # 四个页面
  data/spots.json  30 个合成钓点（固定种子 20261122）
scripts/         # 钓点生成、性能基准
tests/           # vitest：引擎、1cm 精度验收、Worker 端到端
```

## 设计说明

- 所有钓点、天气、潮汐均为**合成虚构数据**，仅用于游戏；但调和公式与物理修正（逆气压、风增水）按真实海洋学关系实现。
- 时区固定东八区（UTC+8），日历日按区时零点锚定。
- Worker 入口同时兼容浏览器 DedicatedWorker 与 Node `worker_threads`（动态 import `node:worker_threads`，浏览器构建自动外置），因此同一文件可做端到端测试。
